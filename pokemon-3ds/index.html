If gameplay is slow

The browser player uses threaded emulation. Use the performance settings to restore native 1× resolution and turn off video filters. You can show the frame rate in the emulator’s Settings under Video.

On a laptop, plug in, close other heavy tabs, and check that graphics acceleration is enabled in Chrome or Edge. If Ultra Sun still runs slowly, try desktop Azahar with your own game dump. It runs outside the browser and can use native CPU and graphics acceleration.
