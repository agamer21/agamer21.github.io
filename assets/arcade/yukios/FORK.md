# AG Arcade YukiOS edition

This is a locally built edition of [YukiOS](https://github.com/Reeyuki/YukiOS), upstream commit `ab3c0a24bfa0ead9450dcf2a26fb935f095358fc`, distributed under the MIT License in `LICENSE`.

The desktop shell, application UI, local wallpapers, icons, and fonts are hosted with AG Arcade. The Yuki Steam store and library list AG Arcade's local game launchers. The game library contains the site games available on this build, including Gang Beasts, the Five Nights at Freddy's browser demo, Subway Surfers, Minecraft: Story Mode, Hill Climb Racing, Aground, and Cat Goes Fishing. Gang Beasts game data and the FNAF demo resources stream from pinned GitHub CDN releases because their complete data does not fit in the site's static bundle.

YukiOS account sync and other optional network services still need their original service endpoints. They are not required to start the desktop or launch AG Arcade games.
